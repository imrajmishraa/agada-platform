# Agada Platform
### Integrated Digital Care Platform for Rural Maharashtra

Available Soon

## Overview

**Agada** (Sanskrit: औषध, meaning "medicine") is an offline-first, microservices-based digital health platform designed to address the acute challenges of rural healthcare access in Maharashtra. It empowers frontline workers (ASHAs, ANMs), strengthens Primary Health Centres (PHCs), and enables seamless care coordination across sub-centres, rural hospitals, and district hospitals.

## Key Features

- 🏥 **Offline-First**: Works without internet, syncs when available
- 📱 **Mobile & Web**: React Native for ASHAs, Web dashboards for doctors
- 🤖 **AI-Assisted Triage**: ML-based risk scoring on mobile
- 📋 **Closed-Loop Referral**: Track referrals end-to-end
- 📞 **Emergency Teleconsultation**: Audio-first, low-bandwidth
- 💊 **Medicine & Diagnostic Tracking**: Real-time stock visibility
- 🌐 **Multilingual**: Marathi, Hindi, English
- 🔗 **Interoperable**: FHIR R4, integrates with ABDM, eSanjeevani

## Architecture

- **Frontend**: React Native (Mobile), React + Vite (Web)
- **Backend**: Node.js, Python microservices
- **Databases**: MongoDB, PostgreSQL, Redis, Elasticsearch
- **Infrastructure**: Docker, Kubernetes-ready
- **Integrations**: ABDM, eSanjeevani, RCH, HMIS
